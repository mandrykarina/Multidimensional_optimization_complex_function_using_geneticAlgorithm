# К защите

Суть: ищем минимум сильно вытянутой квадратичной функции. Особь — девять чисел. При скрещивании смешиваем координаты родителей, при мутации прибавляем небольшой гауссовский шум. Лучшее решение сохраняем. Равный бюджет нужен, чтобы улучшение не объяснялось большим числом попыток.

Почему результат не всегда ноль? Поиск стохастический и ограничен 21 216 оценками; уменьшение шума может остановить продвижение вдоль пологой координаты.

Почему не Растригин? Для номера 17, группы 507, 2026 года получается вариант 16, а не 3.

Откройте `REPORT.md`, покажите формулу, затем `results/runs.csv`, график и `test_model.py`. Объясните один слабый результат и одно ограничение исследования.
